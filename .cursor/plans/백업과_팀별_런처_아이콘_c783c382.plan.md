## 2. 아이콘 생성기

로컬에 Python도 ImageMagick도 없지만 JDK 17(`C:\Program Files\Microsoft\jdk-17.0.20.8-hotspot`)이 있어 Java2D로 렌더합니다. 폰트는 `C:\Windows\Fonts\ariblk.ttf`(Arial Black).

`tools/team-icons/GenTeamIcons.java` — `java GenTeamIcons.java`로 단일 파일 실행. 기존 `app/src/main/res/drawable-nodpi/ic_launcher_foreground_art.png`를 원본으로 읽어:

1. 빨강 계열 픽셀(`#D00F31` 근방)을 팀 컬러로 치환 — 배너와 조명탑 전구가 함께 바뀌어 팀 색으로 통일됩니다
2. 배너 내부를 팀 컬러 단색으로 덮어 `SAJIK` 글자를 지움
3. 그 자리에 구장명을 흰색으로 렌더. 배너 폭에 맞게 자동 축소(`CHANGWON` 8자가 가장 김)
4. adaptive icon 안전영역을 위해 16% 여백을 PNG에 직접 포함 — 지금의 `ic_launcher_foreground.xml` inset 래퍼가 필요 없어져 파일 수가 절반이 됩니다

첫 실행 전에 배너의 정확한 bounding box를 픽셀 스캔으로 뽑는 프로브를 돌립니다. 배너가 사다리꼴이면 사각형 채우기 대신 스캔라인 단위로 덮습니다.

팀 코드와 색은 `teamAccentColor` (`app/src/main/java/com/bossxor/lottegiants/domain/Models.kt:845`)를 그대로 씁니다.

## 4. activity-alias 전환

`AndroidManifest.xml`에서 `MainActivity`의 `MAIN`/`LAUNCHER` 인텐트 필터를 떼고 `sajik://` 딥링크 필터만 남긴 뒤, alias 10개를 추가합니다.

```xml
<activity-alias
    android:name=".Launcher_LT"
    android:targetActivity=".MainActivity"
    android:exported="true"
    android:enabled="true"
    android:icon="@mipmap/ic_launcher_lt"
    android:label="@string/launcher_lt">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity-alias>
```

LT만 `enabled="true"`, 나머지 9개는 `false`.

새 파일 `app/src/main/java/com/bossxor/lottegiants/LauncherIcon.kt`:

- `apply(context, teamCode)` — 켤 alias를 **먼저** 활성화한 뒤 나머지를 비활성화합니다. 순서가 반대면 런처 컴포넌트가 0개인 순간이 생겨 앱이 홈 화면에서 사라집니다
- 전부 `DONT_KILL_APP` 플래그
- 실제 적용은 `MainActivity.onStop()`에서 — 화면이 떠 있는 동안 컴포넌트를 바꾸면 런처가 태스크를 정리해 앱이 튕길 수 있습니다. 전환 요청은 값만 저장해 두고 백그라운드로 갈 때 반영합니다

위젯과 알림의 탭 인텐트는 `Intent(context, MainActivity::class.java)`로 액티비티를 직접 지목하므로(`LotteWidget.kt:133`, `NotificationHelper.kt:671`) alias 전환과 무관하게 그대로 동작합니다.

팀 전환 UI와 `my_team_code` 저장소는 아직 없으므로 이번엔 함수까지만 만들고 호출부 연결은 팀 전환 구현 때 합니다. 검증은 `adb shell pm enable/disable-user`로 alias를 직접 켜 보며 합니다.

## 5. 앱 이름

`values/strings.xml`:

- `app_name` = `집관` — 설정 앱 목록, 알림 헤더, 최근 앱처럼 alias가 못 바꾸는 고정 자리에 쓰입니다
- `launcher_lt` = `집관 사직`, `launcher_ob` = `집관 잠실` … 10개. 홈 화면 아이콘 아래 이름이라 팀을 바꾸면 아이콘과 함께 바뀝니다

화면에 뜨는 `사직스코어`도 같이 정리합니다. 전부 문자열 한 줄씩이라 부작용이 없습니다.

- `ScoreShare.kt:25` 공유 캡션 `#사직스코어`, `:43` 공유 제목
- `MagicNumber.kt:347` 매직넘버 공유 해시태그
- `StandingsScreen.kt:179` `"사직스코어 레이스"`
- `LiveScreen.kt:241,406` 라이브 탭 타이틀
- `MainActivity.kt:546` 온보딩 `"사직스코어 안내"`

반대로 **내부 식별자는 전부 그대로 둡니다.** `sajik://` 딥링크(바꾸면 이미 공유된 링크가 죽음), 패키지 `com.bossxor.lottegiants`(바꾸면 재설치라 설정·스냅샷이 날아감), `Theme.LotteGiants`, GitHub `INV_LotteGiants`와 `LotteGiants.apk`(`UpdateChecker`와 CI가 물려 있음), 로그 TAG `SajikUpdate`. 사용자 눈에 거의 안 띄면서 바꾸는 위험만 큽니다.

## 6. 위젯 추가 화면 중립화

팀을 바꿔도 **위젯을 고르는 화면은 안 바뀝니다.** provider가 하나뿐이라 팀별 preview를 둘 방법이 없습니다. 그래서 아예 팀 색을 빼고 중립으로 만듭니다.

`res/layout/widget_loading.xml`이 `lotte_widget_info.xml`의 `initialLayout`과 `previewLayout` 양쪽에 쓰이는데, 지금은 롯데 네이비에 "롯데 라이브"가 박혀 있습니다.

```xml
<FrameLayout ... android:background="#041E42" ...>
    <TextView ... android:text="롯데 라이브" ... />
</FrameLayout>
```

배경을 중립 회색으로, 텍스트를 `"경기 로딩 중"`으로 바꿉니다. `widget_description`도 `집관 · KBO 실시간 경기 현황`으로 (지금은 "사직스코어 · 롯데 실시간 경기 현황").

위젯을 홈에 올린 뒤의 본문은 Glance라 팀별로 그릴 수 있으니, 정적 리소스인 이 두 곳만 중립이면 됩니다.

## 7. Wear 모듈 삭제

`wear/` 모듈은 완전히 고립돼 있습니다. `app` 모듈 어디에도 `wear` 참조가 없고 `wearApp` 의존성도 없어서, 폰 앱이 워치로 데이터를 보내는 코드 자체가 없습니다. 반면 `SajikSnapshot`의 필드는 `lotteScore`·`starterLotte`·`lotteBatting`이고 타일 라벨 "사직 LIVE", 컴플리케이션 라벨 "롯데 스코어"까지 전부 롯데 고정이라, 살려두면 팀 전환 때 손볼 데만 늘어납니다.

- `wear/` 폴더 (13개 파일) 삭제
- `settings.gradle.kts:24`의 `include(":wear")` 제거
- `gradle/libs.versions.toml`에 wear 전용 의존성이 남으면 같이 정리

## 8. 버전 2.0.0

앱 이름이 바뀌고 런처 아이콘 체계가 통째로 갈리는 변화라 메이저를 올립니다. `app/build.gradle.kts:18-19`:

- `versionName` `1.3.87` → `2.0.0`
- `versionCode` `1095` → `2000`

`versionName` 점프는 안전합니다. `UpdateChecker`는 릴리스 본문에서 정수만 뽑는 `parseVersionCode`(`UpdateChecker.kt:322`)로 `versionCode`만 비교하고, 버전 문자열은 어디서도 파싱하지 않습니다. CI(`publish-latest.yml:47-55`)도 APK badging에서 둘 다 자동으로 읽습니다.

`versionCode`는 지금까지 1씩 올리던 순번인데, 2.x대를 눈에 띄게 구분하려고 `2000`으로 맞춥니다. 커지기만 하면 되므로 건너뛰어도 무방하고, 앞으로 2.0.1은 2001처럼 이어가면 됩니다.

## 알아둘 점

- **기존 홈 화면 바로가기가 깨집니다.** `MainActivity`에서 `LAUNCHER`를 떼면 홈에 놓여 있던 아이콘이 죽은 바로가기가 됩니다. 앱 서랍에는 정상으로 뜨니 한 번 다시 끌어다 놓으면 됩니다. `MainActivity`에 `LAUNCHER`를 남기는 절충안은 아이콘이 두 개 보이거나(남길 때) alias의 `targetActivity`가 죽는(비활성화할 때) 문제라 쓸 수 없습니다
- **배지 재현 정확도** — 색 치환과 글자 덮어쓰기가 원본과 얼마나 자연스럽게 이어지는지는 뽑아 봐야 압니다. LT(원본과 동일해야 함)·두산(어두운 색)·창원(가장 긴 글자) 세 장을 먼저 뽑아 확인받고 나머지를 진행합니다
- LG와 두산은 둘 다 `JAMSIL`이라 배너 색으로만 구분됩니다
- monochrome 아이콘(`ic_launcher_monochrome.xml`)은 글자 없는 구장 실루엣이라 팀 무관합니다. 10개 adaptive icon이 공유합니다
